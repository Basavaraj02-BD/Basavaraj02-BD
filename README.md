### ☁️ [TrackPoint: 3-Tier Deployment on AWS](https://github.com/Basavaraj02-BD/aws-3tier-trackpoint)
A Django application (TrackPoint / TPMS) deployed on a production-style three-tier AWS architecture.
- **Presentation tier:** Application Load Balancer
- **Application tier:** EC2 instance in a private subnet
- **Data tier:** RDS MySQL
- **Setup:** Custom VPC in `ap-south-1` (Mumbai), with the app and database networked together inside one VPC
- **What I learned:** Debugging VPC networking and database connectivity, and rebuilding the whole environment from scratch when the first design had connection issues
- 📄 Architecture docs are in the repo
